When creating ANY component:

1. STRUCTURE:
   - Create folder with: Component.tsx, styles.module.css, index.ts, Component.test.tsx
   - Use functional components with TypeScript interfaces
   - Export through index.ts barrel file

2. STYLING:
   - Use CSS modules with neural naming conventions
   - Implement both dark/light theme variants
   - Apply glass morphism to elevated elements
   - Add neural glow effects for interactions

3. ANIMATIONS:
   - Use Framer Motion for complex orchestrations
   - CSS animations for simple micro-interactions
   - Ensure 60 FPS performance
   - Add stagger effects for lists

4. STATE:
   - Use Zustand for global state
   - React Query for server state
   - Local state with useState/useReducer
   - Implement optimistic updates

5. ACCESSIBILITY:
   - Semantic HTML elements
   - ARIA attributes where needed
   - Focus management
   - Screen reader testing

6. TESTING:
   - Unit tests with React Testing Library
   - Integration tests for user flows
   - Visual regression tests
   - Performance tests
